# NitiPlay LLC — Official Website

Premium marketing website for **NitiPlay LLC**, a mobile app publishing company focused on high-quality iOS & Android games and gaming utility apps.

## Tech Stack

- **Next.js 16** (App Router)
- **React 19** + **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion** for animations
- **Lucide React** for icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
npm start
```

## Environment Variables

```env
NEXT_PUBLIC_SITE_URL=https://nitiplay.com
```

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — hero, stats, featured apps, services, testimonials, FAQ, CTA |
| `/about` | Company story & founder profile (Ismail Lahniti) |
| `/portfolio` | Filterable app portfolio |
| `/services` | Publishing, utilities, design, partnerships |
| `/our-apps` | Full app catalog with store badges |
| `/contact` | Contact form & company info |
| `/privacy` | Privacy policy |

## Brand Assets

- `public/logo.svg` — Full logo mark (512×512, app icon ready)
- `public/favicon.svg` — Browser favicon
- `src/components/ui/Logo.tsx` — Inline SVG logo component (light/dark compatible)
